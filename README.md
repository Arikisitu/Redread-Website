🔴 RedRead
Read. Discover. Repeat.

RedRead is a modern manga reading experience designed with simplicity, immersion, and discovery in mind.
Built around a dark cinematic aesthetic, RedRead keeps the interface focused so the content stays at the center.
✦ Highlights
- Clean and focused reading experience
- Manga discovery and browsing
- Personal library
- Dedicated source management
- Customizable visual experience
- Smooth and responsive interface
- Dark-first cinematic design
🎨 Visual Identity
RedRead combines deep blacks, rich burgundy tones, warm highlights, and subtle motion to create a distinctive visual language.
The design is intentionally minimal, atmospheric, and consistent across the app and website.
🖼️ Screenshots
The website includes a curated gallery showcasing the RedRead experience.
The gallery supports up to six screenshots in a clean three-column layout on desktop and adapts for smaller screens.
⚡ Philosophy
RedRead is built around a simple principle:
Less distraction. More reading.

Every part of the experience is designed to keep navigation clear, presentation elegant, and reading at the forefront.
🛠️ Technology
This website is built as a lightweight static site using:
- HTML
- CSS
- JavaScript
No heavy framework is required.
📄 Project
RedRead is an independent project based on the open-source Futon Android project.
Relevant upstream attribution and licensing information are preserved in the project repository.
